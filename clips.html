Field manual · 5 minutes to set up

Clip it in one key.

You don't need to record everything. Free tools quietly keep the last 30 seconds to a few minutes of your game. When something glorious happens, press one key and the clip is saved.

Which one is yours?

Not sure what's in your PC? Medal works on any Windows PC.

NVIDIA · free NVIDIA app

Instant Replay

  1. Install the free NVIDIA app from nvidia.com if you don't have it.
  2. In WoW, press Alt + Z to open the overlay and make sure recording is allowed.
  3. Turn on Instant Replay: Alt + Shift + F10. In the overlay you can set how long it keeps (start with 1 minute).
Save the momentAlt + F10Clips go to your Videos folder.
AMD · AMD Software: Adrenalin Edition

Instant Replay

  1. Open AMD Software (right-click the desktop) → Record & Stream.
  2. Switch on Instant Replay and pick how long it keeps (start with 1 minute).
  3. Check your save key: search Hotkey in AMD Software → Media Hotkeys → Save Instant Replay.

Any Windows PC · free app

Medal

  1. Install Medal from medal.tv and sign in.
  2. Start WoW Forever. Medal records in the background.
  3. In Medal's Clip Settings, pick the length: 30 or 60 seconds is plenty.
Save the momentF8Medal gives you a share link, perfect for the BigD form.
Windows 10 / 11 · already installed

Xbox Game Bar

  1. Open Settings → Gaming → Captures.
  2. Turn on Record what happened (background recording).
  3. Play. Windows keeps the last 30 seconds by default.
Save the momentWin + Alt + GClips go to Videos → Captures.
Mac

Screen recording or OBS

  1. Quick way: press Cmd + Shift + 5 → Record before a fight you expect. Stop it from the menu bar.
  2. One-key way: install free OBS Studio → Settings → Output → turn on Replay Buffer → Settings → Hotkeys → set a key for Save Replay. Click Start Replay Buffer before you play.

Make it count

Turn on chat timestamps

In WoW's Options, find Chat Timestamps (Social). Kill messages with a time are much stronger proof.

Screenshots work too

Press Print Screen in game. Show the kill message in chat. Find them in the Screenshots folder inside your WoW Forever folder.

Keep it short

15–60 seconds. Start just before the action, end on the kill (or the death).

Getting it to us

Medal gives a link. Other clips: upload to YouTube as Unlisted and paste the link, or drop small files straight into Discord.
